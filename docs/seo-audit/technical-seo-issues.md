# Technical SEO Issues

| Issue ID | Category | Severity | Verified Evidence / File Location | Technical Root Cause | Recommended Fix | Testing & Verification Method |
| --- | --- | --- | --- | --- | --- | --- |
| TECH-01 | Crawl / 404 Routing | Critical | GSC Top Pages shows '/service/custom-software-development' (2 imp, pos 7.00). In App.tsx, route is '/services/:id'. | Legacy or external link uses singular '/service/' which triggers React Router's '*' NotFound fallback. | Add 301 redirects in vercel.json: redirect '/service/(.*)' to '/services/$1', and explicitly '/service/custom-software-development' to '/services/software'. | Curl request: 'curl -I https://www.aiscripto.com/service/custom-software-development' expecting HTTP 301 to /services/software. |
| TECH-02 | Indexing / Canonicalization | Critical | index.html (Line 24): <link rel="canonical" href="https://www.aiscripto.com/" /> is hardcoded in raw HTML. | React SPA dynamically updates canonical in Seo.tsx via DOM, but raw static HTML served to crawlers contains homepage canonical for every single URL. | Remove hardcoded canonical tag from index.html head. Let Seo.tsx inject canonical dynamically, or implement serverless edge prerendering. | Inspect raw curl output of sub-pages without JS execution: ensure canonical tag is not hardcoded to root. |
| TECH-03 | Metadata / Title Tag | High | src/pages/ServiceDetail.tsx (Line 410): <Seo title={`${data.title} \| AIScripto`} /> while Seo.tsx uses SEOConfig.titleTemplate '%s \| AIScripto'. | String concatenation creates double branding: 'AI Agents & Automation \| AIScripto \| AIScripto' across all service detail pages. | In ServiceDetail.tsx, pass only 'title={data.title}' so Seo.tsx formats it cleanly into 'AI Agents & Automation \| AIScripto'. | View document.title in browser DOM on /services/ai and /services/erp; confirm single clean brand suffix. |
| TECH-04 | Heading Hierarchy | High | src/pages/Home.tsx (Line 127): <h1 className="sr-only">...</h1> while visible hero headings are H2s inside carousel. | H1 is visually hidden using CSS sr-only. Search engine guidelines favor primary visible H1 matching page topic. | Replace sr-only H1 with visible hero H1 highlighting enterprise AI solutions, automation, and software engineering. | Run Lighthouse SEO audit; verify single prominent visible H1 tag in accessibility and heading outline. |
| TECH-05 | Structured Data (Schema) | Medium | index.html only includes WebSite and Organization schema. ProductDetail.tsx includes SoftwareApplication, but Service pages have NO schema. | Service pages lack Service schema; Case studies lack CaseStudy schema; Local offices lack LocalBusiness schema. | Inject structured Schema.org JSON-LD via Seo.tsx for: (1) Service schema on all /services/*, (2) LocalBusiness on /contact and /global, (3) Article/BlogPosting on /blog/*. | Validate URLs using Google Rich Results Test and Schema.org Validator. |
| TECH-06 | Generic Title Tags | Medium | Services.tsx ('Our Services'), Company.tsx ('Company'), Insights.tsx ('Insights'), CaseStudies.tsx ('Case Studies'). | Static title strings in Seo component calls omit target keywords and commercial modifiers. | Rewrite all hub page titles with descriptive keyword modifiers (e.g., 'Enterprise AI, Cloud & Software Services \| AIScripto'). | Review Page Titles across all routes using Screaming Frog or site crawl. |
| TECH-07 | SPA Client Rendering Lag | Medium | All routes rendered entirely client-side via React 19 / Vite. Googlebot must execute JS to discover internal links and content. | First wave of Googlebot crawler indexes HTML shell (<div id="root"></div>) before Web Rendering Service executes JS. | Implement prerendering using Vite prerender plugins (e.g., vite-plugin-prerender) or edge SSR caching for critical commercial landing pages. | Test pages in Google Search Console URL Inspection Tool via 'Test Live URL' to verify rendered HTML matches source. |
